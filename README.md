# Marcenaria Irmãos França

Site institucional responsivo de marcenaria e móveis planejados sob medida. A identidade visual usa tons de marfim, areia, nogueira, grafite e dourado envelhecido.

## Recursos

- Portfólio com filtros por ambiente e ampliação das imagens.
- Simulador 3D com opções de móvel, acabamento, dimensões, portas e prateleiras.
- Prévia de plano de corte e lista de peças, sujeitas à revisão técnica.
- Campos para inserir os custos reais da marcenaria e calcular um orçamento.
- Formulário que prepara uma mensagem para enviar pelo WhatsApp.
- Alternância de tema claro/escuro e layout adaptável a celular.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, a pasta `images/` e este README para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch principal e a pasta **/(root)**, depois salve.
6. Aguarde a publicação e acesse o endereço indicado pelo GitHub Pages.

## Antes de publicar

- Configure o número oficial de WhatsApp e revise os dados de localização e atendimento.
- Confira as opções de materiais disponíveis na marcenaria.
- Revise a prévia de corte e a lista de peças com um profissional antes de fabricar. As folgas, ferragens e medidas finais dependem do projeto aprovado.
- Preencha os custos reais na aba Orçamento. Os campos estão vazios intencionalmente.
- O espaço de depoimentos está identificado para receber relatos reais com autorização dos clientes.

## Arquivos

- `index.html` — página e recursos interativos.
- `images/` — imagens dos trabalhos fornecidas para o site.
